# What the AP Chemistry exam covers

Checked against the College Board's *AP Chemistry Course and Exam Description* (effective fall 2024) and the *AP Chemistry Equations and Constants* sheet (© 2025). Use this when a lab says what the exam does or doesn't test. Paraphrased; see the CED for exact wording.

## Exclusion statements (not assessed on the AP Exam)

| Topic | Not assessed |
|---|---|
| 1.2 | Mass spectra of samples with more than one element, or peaks from anything other than singly charged monatomic ions |
| 1.5 | Assigning quantum numbers to electrons |
| 1.7 | Writing electron configurations for exceptions to the aufbau principle (Cr, Cu, …) |
| 2.3 | Knowledge of specific crystal structures |
| 2.7 | Derivation and depiction of hybrid orbitals (sp, sp², sp³ names, sigma vs. pi, and VSEPR shapes **are** in the course) |
| 2.7 | Hybridization involving d orbitals; for more than four electron pairs around the central atom, only the shape is required |
| 2.7 | Molecular orbital diagrams, filling MOs, and bonding/nonbonding/antibonding distinctions |
| 3.3 | Understanding or interpreting phase diagrams |
| 3.8 | Colligative properties |
| 3.8 | Calculating molality, percent by mass, or percent by volume **for solutions** |
| 4.7 | The meaning of the terms "oxidizing agent" and "reducing agent" |
| 4.7 | Memorizing solubility rules beyond: all sodium, potassium, ammonium, and nitrate salts are soluble in water |
| 4.8 | Lewis acid–base concepts (the course emphasizes reactions in aqueous solution) |
| 5.6 | Calculations with the Arrhenius equation |
| 5.7–5.8 | Collecting data on detecting a reaction intermediate |
| 6.6 | Technical distinctions between enthalpy and internal energy |
| 6.9 | The concept of state functions |
| 7.3 | Converting between Kc and Kp (students should know the conceptual difference) |
| 7.3 | Equilibrium calculations for a dissolved species in equilibrium with the same species in the gas phase |
| 8.5 | Computing the concentration of each species along a polyprotic acid's titration curve (monoprotic is in scope; qualitative polyprotic reasoning is in scope) |
| 8.9 | Computing the pH change when acid or base is added to a buffer |
| 8.9 | Deriving the Henderson–Hasselbalch equation |
| 8.11 | Computing solubility as a function of pH |
| 9.8 | Labeling an electrode as positive or negative |

Topic numbers are the CED topic each statement appears under.

## Equations and constants sheet (given on the exam)

- **Atomic structure:** E = hν, c = λν, F ∝ q₁q₂/r²; h = 6.626 × 10⁻³⁴ J·s, c = 2.998 × 10⁸ m/s, Avogadro's number = 6.022 × 10²³ mol⁻¹.
- **Gases, liquids, solutions:** P₁V₁/T₁ = P₂V₂/T₂, PV = nRT, P_A = P_total × X_A, P_total = P_A + P_B + …, n = m/M, D = m/V, KE = ½mv², M = n_solute / L solution, A = εbc; R = 8.314 J/(mol·K) = 0.08206 L·atm/(mol·K); STP = 273.15 K and 1.0 atm; ideal gas at STP = 22.4 L/mol.
- **Kinetics:** [A]ₜ − [A]₀ = −kt; ln[A]ₜ − ln[A]₀ = −kt; 1/[A]ₜ − 1/[A]₀ = kt; t½ = 0.693/k.
- **Equilibrium:** Kc, Kp expressions; Kw = [H₃O⁺][OH⁻] = 1.0 × 10⁻¹⁴ at 25 °C; pKw = 14 = pH + pOH; pH = −log[H₃O⁺], pOH = −log[OH⁻]; Ka, Kb expressions; pKa = −log Ka, pKb = −log Kb; Kw = Ka × Kb, pKw = pKa + pKb; pH = pKa + log([A⁻]/[HA]).
- **Thermodynamics / electrochemistry:** q = mcΔT; ΔH°rxn = ΣΔH°f(products) − ΣΔH°f(reactants); ΔS°rxn = ΣS°(products) − ΣS°(reactants); ΔG°rxn = ΣΔG°f(products) − ΣΔG°f(reactants); ΔG° = ΔH° − TΔS° = −RT ln K = −nFE°; I = q/t; Ecell = E°cell − (RT/nF) ln Q; F = 96,485 C/mol e⁻.
- **Units:** 1 atm = 760 mm Hg = 760 torr; K = °C + 273.15.

**Not on the sheet:** ΔG = ΔG° + RT ln Q, the Arrhenius equation, R = 62.36 L·torr/(mol·K), M₁V₁ = M₂V₂ (dilution), percent yield, and Rf.
