Common-Ion Effect Study Lab

A salt dissolves less in a solution that already contains one of its ions. Le Châtelier’s principle explains why: the extra ion pushes the dissolution equilibrium back toward the solid. Ksp lets you calculate by how much. Here you choose a salt and a source of a common ion, set its concentration, and compare the solubility with the value in pure water.

2. Key ideas

Qualitative

Le Châtelier explains it

For AgCl(s) ⇌ Ag+ + Cl−, Cl− from NaCl is a product already present. The equilibrium lies further toward the solid, so less AgCl dissolves. Adding NaCl to a saturated AgCl solution makes some AgCl precipitate.

Quantitative

Start the ICE table at C, not 0

In 0.10 M NaCl, [Cl−] starts at 0.10 M and becomes 0.10 + s. Then Ksp = (s)(0.10 + s). Everything else is the same as in pure water.

The shortcut

Drop s next to C

Because s is tiny compared with the common-ion concentration, 0.10 + s ≈ 0.10, so s ≈ Ksp/0.10. Check that s really is far below C. The approximation fails only when C is about as small as the pure-water solubility.

Ksp stays put

Solubility changes, Ksp doesn’t

Ksp depends only on temperature. The common ion changes how the ion product is split between the two ions, so less salt dissolves; the product itself still equals Ksp.

Which ion matters more

Watch the exponent

For PbI2, 0.10 M I− lowers the solubility far more than 0.10 M Pb2+, because [I−] is squared in Ksp: s ≈ Ksp/(0.10)2 versus s ≈ √(Ksp/0.40).

Experiments

A hidden common ion skews results

If a solubility is measured in a solution that already holds a common ion, but Ksp is calculated as if it were pure water, the measured s is too low and so is the calculated Ksp.

4. The common-ion effect on the FRQ

What earns points on the FRQ

  • Identify the common ion and its initial concentration from the dissolved salt (0.10 M CaCl2 gives 0.20 M Cl−).
  • Write the Ksp expression with the common ion as C + s (or C + 2s), then justify dropping s.
  • For a qualitative answer, name Le Châtelier’s principle and the direction of the shift: toward the solid.
  • State that Ksp is unchanged; only the solubility changes.
  • Compare with the pure-water solubility to show the decrease, with both values in mol/L.
  • For lab-design questions, trace how an unnoticed common ion changes the measured solubility and the calculated Ksp.

Common mistakes

  • Starting the common ion at zero in the ICE table.
  • Forgetting that a salt like CaCl2 supplies two Cl− per formula unit.
  • Saying Ksp decreases when a common ion is added.
  • Forgetting to square C when the common ion has a coefficient of 2: for PbI2 in 0.10 M NaI, Ksp ≈ s(0.10)2.
  • Using 2C instead of C: in 0.10 M NaI, [I−] is 0.10 M, not 0.20 M. The 2 belongs only to the I− that comes from PbI2.
  • Expecting a salt with no ion in common (such as NaNO3 for AgCl) to lower the solubility.
