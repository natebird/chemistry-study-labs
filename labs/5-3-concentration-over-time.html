2. Key ideas

The test

Find the straight line

Plot [A], ln[A], and 1/[A] against time. Exactly one should be linear. [A] linear means zero order, ln[A] linear means first order, 1/[A] linear means second order in A.

Slope → k

Watch the sign

Zero order: slope of [A] vs. t = −k. First order: slope of ln[A] vs. t = −k. Second order: slope of 1/[A] vs. t = +k, because 1/[A] grows as [A] shrinks. k itself is always positive.

Equation sheet

Integrated rate laws

[A]t − [A]0 = −kt; ln[A]t − ln[A]0 = −kt; 1/[A]t − 1/[A]0 = kt. Each is a straight line y = mx + b in the variable that makes it linear. Use them to find a concentration at a time, or the time to reach a concentration.

First order

Constant half-life

For a first-order reaction the half-life is the same no matter how much is left: t½ = 0.693/k. After n half-lives, (½)n of the starting amount remains. For zero and second order, the half-life changes as the reaction goes on.

Nuclear

Radioactive decay

Every radioactive decay is first order: each nucleus has the same chance of decaying per unit time, so the decay rate is proportional to the number of nuclei. That is why each isotope has a fixed half-life.

Shape of [A] vs. t

Curves you can recognize

Zero order: a straight downward line that hits zero. First order: an exponential decay. Second order: drops fast at first, then has a long, slow tail. Only the linear-plot test proves the order; shapes just hint at it.

4. Concentration–time data on the FRQ

What earns points on the FRQ

  • Justify the order with the graph: "The plot of ln[A] versus time is linear, so the reaction is first order with respect to A."
  • Get k from the slope with the right sign and units: "slope = −0.0115 s−1, so k = 0.0115 s−1."
  • For a first-order half-life, write t½ = 0.693/k and substitute with units.
  • Use the integrated law that matches the order, and keep ln and log separate: the equation sheet uses ln.
  • For "how long until 12.5% remains" with first order, count half-lives: 100 → 50 → 25 → 12.5% is three half-lives.
  • When data show equal times for each halving, say so: a constant half-life is evidence of first order.

Common mistakes

  • Reporting k as negative because the slope of ln[A] vs. t is negative.
  • Choosing the order from the shape of the [A] vs. t curve alone. A first- and a second-order curve can look alike over a short time.
  • Using log (base 10) instead of ln.
  • Using t½ = 0.693/k for a reaction that is not first order.
  • Forgetting that the 1/[A] plot for second order slopes upward.
  • Mixing time units: if k is in min−1, t must be in minutes.
