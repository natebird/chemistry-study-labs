    2. Key ideas

    Step 1

    React first, with moles

    A strong acid or strong base reacts essentially completely with any acid or base it meets. So start with a before–change–after table in moles (or mmol): the limiting reactant goes to zero, and the other is reduced by the same amount. Equilibrium comes second.

    Why "complete"

    Huge K values

    H₃O⁺ + OH⁻ → 2H₂O has K = 1/Kw = 1.0 × 1014. HA + OH⁻ → A⁻ + H₂O has K = Ka/Kw, which is 1.8 × 109 for acetic acid. Values that large mean the limiting reactant is used up.

    Step 2

    Excess strong acid or base

    If strong acid or strong base is left over, it controls the pH: [H₃O⁺] or [OH⁻] = moles in excess ÷ total volume (in liters). The weak conjugate that is also present barely matters next to it.

    Step 2

    Weak + its conjugate = buffer

    If some weak acid HA is left along with its conjugate base A⁻ (or B with BH⁺), the mixture is a buffer. Use pH = pKa + log([A⁻]/[HA]); both are in the same volume, so the mole ratio works. When the two are equal, pH = pKa.

    Step 2

    Only the conjugate is left

    When a weak acid and a strong base are exactly equimolar, only A⁻ remains, and it is a weak base: Kb = Kw/Ka, so the solution is slightly basic. Weak base + strong acid at equal moles leaves BH⁺, which is slightly acidic. Strong + strong at equal moles is neutral.

    Weak + weak

    An equilibrium, not completion

    HA + B ⇌ A⁻ + BH⁺ has K = Ka(HA) × Kb(B) / Kw. Acetic acid and ammonia give K ≈ 3 × 104, so the reaction lies far to the right, but a very weak acid such as HCN gives K near 1, a true mixture of reactants and products.

    4. Mixtures and buffers on the FRQ

    What earns points on the FRQ

    • Write the net ionic equation for the neutralization with the weak acid or base as a molecule: CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O, not H⁺ + OH⁻.
    • Convert every volume and molarity to moles first, then subtract. Graders look for the moles of each species remaining.
    • Name the situation before calculating: "HA and A⁻ are both present in significant amounts, so the solution is a buffer."
    • For a buffer, write pH = pKa + log([A⁻]/[HA]) and show the ratio. Mole amounts can replace concentrations because the volume cancels.
    • For excess strong base, divide the excess moles of OH⁻ by the total volume of the mixture, not the volume of base added.
    • At equal moles of weak acid and strong base, justify "basic" with the reaction A⁻ + H₂O ⇌ HA + OH⁻.

    Common mistakes

    • Plugging starting concentrations into Ka or Henderson–Hasselbalch before letting the strong acid or base react.
    • Saying any equimolar acid–base mixture has pH 7. Only strong + strong does.
    • Using the volume of one solution instead of the total volume after mixing.
    • Calling a weak acid + excess strong base a buffer. Once the weak acid is gone, there is no buffer, only excess OH⁻.
    • Flipping the ratio in Henderson–Hasselbalch: it is base over acid, [A⁻]/[HA], so more conjugate base means pH above pKa.
    • Mixing HCl with NaCl and calling it a buffer. Cl⁻ is the conjugate of a strong acid and does not react with H₃O⁺, so nothing resists pH change.
